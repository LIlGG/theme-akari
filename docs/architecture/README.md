# Akari 开发资料

此目录只保存对当前代码仍有约束力的长期文档。迁移计划、旧 MVP、逐轮验收记录和临时截图不属于代码事实，不再进入仓库，避免维护者或 Agent 误用历史实现。

## 阅读顺序

1. [开发指南](./DEVELOPMENT.md)：源码边界、Halo 数据、Astro 构建、客户端生命周期和修改流程。
2. [设计系统](./DESIGN_SYSTEM.md)：主题气质、视觉层级、尺寸依据、动效和无障碍原则。
3. [发布流程](./PUBLISHING.md)：仓库和 Halo 应用市场准备完成后使用。

面向主题使用者的说明位于 [主题使用说明](../USER_GUIDE.md)，README 展示图位于 [`../images/`](../images/)。

## 事实优先级

发生冲突时，按以下顺序判断：

1. 当前源码、`theme.yaml`、`settings.yaml` 与 `annotations.yaml`；
2. Halo 当前运行时的实际输出；
3. 本目录中的设计与维护原则；
4. Git 历史中的旧方案和截图。

开发文档解释“为什么这样维护”，不复制所有实现细节。具体选择器、配置字段和版本号应直接从源码确认。
