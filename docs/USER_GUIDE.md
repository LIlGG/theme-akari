# 晚灯小屋 Akari 主题使用说明

这份说明面向第一次使用 Akari 的站长。只需要按照下面的顺序完成 Halo 的站点信息、插件、自定义页面、主题设置、菜单和文章内容。

> 推荐顺序：**站点资料 → 插件 → 主题设置 → 自定义页面 → 菜单 → 文章与媒体内容 → 上线检查**。

## 1. 安装并启用主题

Akari 需要 Halo 2.25 或更高版本。

推荐优先从 [Halo 应用市场](https://www.halo.run/store/apps/app-8rojpuw1) 安装；需要手动安装时，可从 [GitHub Release](https://github.com/LIlGG/theme-akari/releases) 下载主题 ZIP。

1. 登录 Halo Console，进入 **外观 → 主题**。
2. 点击主题管理中的安装入口，上传 Akari 的 ZIP 文件。
3. 安装完成后，选择 **晚灯小屋 Akari** 并点击启用。
4. 进入主题设置，确认可以看到“小屋身份、首页、内容来源与规则、外观与动效、页脚”五组设置。

如果升级主题后缺少新的设置项或自定义模板，请在主题详情右上角的更多操作中执行一次 **重载主题配置**。重载只更新主题提供的设置结构，不等于清空已经填写的内容。

## 2. 先完善 Halo 的站点与站长资料

Akari 会优先复用 Halo 已经保存的信息，所以这些内容不需要在主题设置中重复填写。

### 站点资料

在 Halo 的站点设置中建议完成：

- 站点标题与副标题；
- 站点 Logo 与浏览器图标；
- SEO 描述；
- 站点语言和时区。

### 站长资料

在用户资料中填写显示名称、头像和个人简介。首页屋主卡片会优先读取最新文章作者的资料；当站点还没有文章时，才会回退到站点标题、Logo 和 SEO 描述。

如果是多人博客，首页会自然展示最新一篇文章的作者，而不是固定展示某个账号。

## 3. 按需要安装插件

在 Halo Console 的应用市场中搜索并启用下列插件。只安装你真正会使用的能力即可。

| 插件     | 应用市场                                          | 用途                                 |
| -------- | ------------------------------------------------- | ------------------------------------ |
| 评论组件 | [打开](https://www.halo.run/store/apps/app-YXyaD) | 文章回应、留言簿、瞬间和相册详情评论 |
| 图库管理 | [打开](https://www.halo.run/store/apps/app-BmQJW) | `/photos` 相册与图片详情             |
| 瞬间     | [打开](https://www.halo.run/store/apps/app-SnwWD) | `/moments` 瞬间列表与详情            |
| 链接管理 | [打开](https://www.halo.run/store/apps/app-hfbQg) | `/links` 友链分组与站点资料          |
| 搜索组件 | [打开](https://www.halo.run/store/apps/app-DlacW) | 页眉搜索按钮与 `/search` 页面        |

## 4. 配置主题

进入 **外观 → 主题 → 晚灯小屋 Akari → 设置**。

### 4.1 小屋身份

| 设置项     | 用途               | 建议                                              |
| ---------- | ------------------ | ------------------------------------------------- |
| 页眉 Logo  | 导航左侧的品牌标志 | 使用透明 PNG、WebP 或 SVG；留空会使用主题内置标志 |
| 主题品牌名 | Logo 右侧的主标题  | 建议 2–8 个字符，例如“Akari”或“晚灯”              |
| 品牌副标题 | 品牌名下方的小字   | 一句简短的小屋名字；留空会使用 Halo 站点副标题    |

这里仅控制主题页眉的品牌呈现，不会覆盖 Halo 的站点标题和 SEO 标题。

### 4.2 首页

| 设置项             | 显示位置         | 建议                                               |
| ------------------ | ---------------- | -------------------------------------------------- |
| 眉题               | 首页欢迎标记     | 可以是一句短日文、日期感词语或栏目名               |
| 主标题第一、二行   | 首页主标题       | 分成两行控制节奏，每行尽量不超过 12 个汉字         |
| 纸条标题、今日纸条 | 主视觉右下角     | 写一条会随站点气质变化的小句子                     |
| 主视觉背景         | 首页右侧主图     | 4:3、长边至少 1440 px，主体靠右且留有明暗层次      |
| 角色立绘           | 主视觉中的人物层 | 透明 PNG 或 WebP，长边建议至少 1800 px             |
| 季节标签           | 自动季节编号下方 | 例如“樱色晚风”“盛夏汽水”；编号会按当前月份自动推算 |

不上传主视觉背景时会使用主题内置的温馨夜景回退图。角色图留空时，主题不会伪造站长身份信息，只使用视觉回退资源完成构图。

### 4.3 内容来源与规则

| 设置项                 | 作用                                                                       |
| ---------------------- | -------------------------------------------------------------------------- |
| 首页正在播放           | 选择“最近生活拼贴”和媒体室优先展示的媒体文章；留空时自动使用较新的文章补位 |
| 首页书架推荐           | 选择首页书架卡片对应的文章；留空时按最新文章补位                           |
| 最近文章默认封面一至三 | 仅在对应文章没有封面时显示                                                 |
| 在听、在看、在读分类   | 决定媒体室三个书影音分区分别读取哪些文章                                   |
| 留言与文章回应字数     | 控制主题化评论编辑器的输入上限                                             |
| 显示首页天气           | 根据访客所在位置显示附近天气                                               |

首页的“最近生活拼贴”主卡和“最近写下的”均按文章发布时间读取最新内容。想让刚发布的文章出现在首页，请确认文章已经发布、发布时间正确，并且可见性不是私密。

### 4.4 外观与动效

- **默认配色**：可选择跟随系统、明亮或深色。
- **允许访客切换配色**：开启后，页眉显示明暗模式按钮，并记住访客选择。
- **强调色**：影响按钮、链接、标签和选中状态。建议使用中等明度、不过度饱和的颜色。

Akari 会自动尊重访客系统中的“减少动态效果”设置，不需要额外配置。

### 4.5 页脚

- **页脚标语**：适合放一句简短、有温度的话。
- **自定义版权**：留空时自动显示当前年份和 Halo 站点标题。

## 5. 创建 Akari 自定义页面

自定义页面是 Akari 的“房间”。主题通过页面所选择的模板识别它的用途，因此页面别名不需要固定为 `/posts`、`/about` 等地址。

在 Halo Console 中进入 **内容 → 页面**，新建页面并完成：

1. 填写页面标题；
2. 设置便于记忆的别名；
3. 填写摘要；
4. 打开页面的高级设置，选择对应的 Akari 自定义模板；
5. 发布页面。

| 推荐页面   | 选择的模板 | 页面内容如何使用                                                           | 插件要求 |
| ---------- | ---------- | -------------------------------------------------------------------------- | -------- |
| 手记       | 手记总览   | 标题作为页首标题；摘要作为副标题；留空摘要时自动组合热门分类、文章数和季节 | 无       |
| 关于       | 关于小屋   | 页面封面可作为角色图；摘要作为个人介绍回退；正文显示在个人卡片下方         | 无       |
| 分类与标签 | 分类与标签 | 标题和摘要用于页首；分类、标签及数量来自 Halo                              | 无       |
| 媒体室     | 媒体室     | 标题和摘要用于页首；在听、在看、在读来自主题设置中的三个分类               | 无       |
| 留言簿     | 留言簿     | 标题和摘要用于页首；需要开启页面评论                                       | 评论组件 |
| 友邻       | 友邻门牌   | 页面用于提供友链页地址和专属文案；友链卡片来自链接管理                     | 链接管理 |

### 关于页面的专属字段

当页面模板选择“关于小屋”后，页面设置中会出现 Akari 专属字段：

- **关于页角色题签**：例如 `ORIGINAL SPIRIT`；
- **正在做**：一句当前状态；留空时使用最新文章标题；
- **最近在看**：一句近期兴趣；留空时使用页面摘要或站点描述。

关于页正文可以自由使用 Halo 编辑器编写。没有正文时，主题会自然收起下面的内容区，不保留多余横线。

### 友邻页面的专属字段

当页面模板选择“友邻门牌”后，可以设置：

- 页首眉题；
- 视觉标题；
- 副标题；
- “关于这些门牌”的标题与说明。

友链站点的名称、地址、Logo、描述、分组和顺序仍然在 **链接管理插件** 中维护。Logo 加载失败时，Akari 会使用站点名称的首字作为回退头像。

## 6. 设计主菜单

Halo 的主菜单就是 Akari 的页眉导航。进入 **外观 → 菜单**：

1. 新建一个菜单，或选择现有菜单；
2. 将它设置为主菜单；
3. 添加首页、自定义页面和已启用插件的页面入口；
4. 拖拽调整顺序；
5. 编辑每个菜单项的 Akari 字段。

### 推荐菜单结构

| 显示位置 | 推荐入口                               |
| -------- | -------------------------------------- |
| 主导航   | 小屋、手记、相册、瞬间、关于           |
| 更多     | 归档、分类与标签、媒体室、友邻、留言簿 |

“小屋”使用自定义链接 `/`。手记、关于、分类与标签、媒体室、友邻和留言簿应选择你刚创建的自定义页面，而不是手写固定地址。相册、瞬间和搜索使用对应插件提供的入口。

### 菜单项的 Akari 字段

- **菜单图标**：在 Iconify 选择器中挑选与页面含义一致的线性图标；留空时使用通用闪光图标。
- **导航位置**：选择“主导航”或“收纳进更多”。
- **菜单补充说明**：只显示在“更多”面板中，例如“沿时间慢慢翻”或“收藏书影音与声音”。

如果不指定导航位置，Akari 默认把前 5 个菜单项放入主导航，其余收纳进“更多”。为了在不同屏幕上保持一致，建议仍为每个一级菜单项明确选择位置。

Akari 当前以一级菜单为主要导航单位。需要层级很多的内容，更适合通过“分类与标签”页面组织，而不是堆叠多层导航。

## 7. 准备文章与首页内容

### 普通文章

为了让列表、归档和首页卡片完整，建议每篇文章都填写：

- 清晰的标题；
- 一张横向封面；
- 1–2 句摘要；
- 至少一个分类；
- 必要的标签。

阅读时间会根据正文自动计算。如果某篇文章需要人工校准，可以填写文章设置中的 **预计阅读分钟数**。

### 媒体札记

音乐、影视和阅读记录可以在文章高级设置中选择 **媒体札记** 模板，并填写 Akari 媒体字段：

| 字段         | 在听                        | 在看                 | 在读                      |
| ------------ | --------------------------- | -------------------- | ------------------------- |
| 媒体类型     | 选择“在听”                  | 选择“在看”           | 选择“在读”                |
| 媒体副标题   | 歌手、专辑或一句听感        | 作品副题或一句观后感 | 作者、版本或一句读后感    |
| 进度或评分   | 通常留空                    | 集数、完成度或评分   | 阅读进度或评分            |
| 主音视频附件 | 上传或从附件库选择音频/视频 | 需要播放视频时选择   | 通常留空                  |
| 补充信息     | 情绪、场景或年份            | 导演、年份或心情     | 作者、出版社或年份        |
| 书架角标     | 可选                        | 可选                 | 例如 `VOL.03`、`春季在读` |

主音视频请使用附件选择器，不要粘贴本机路径。文章正文中需要多段音视频时，可以直接在 Halo 编辑器中插入任意数量的音频或视频节点。

### 首页各区域的取值顺序

| 首页区域         | 取值规则                                         |
| ---------------- | ------------------------------------------------ |
| 屋主卡片         | 最新文章作者；无文章时回退站点资料               |
| 最近生活拼贴主卡 | 最新发布文章                                     |
| 正在播放         | 主题设置指定文章；未指定时自动补位               |
| 我的书架         | 主题设置指定文章；未指定时自动补位               |
| 最近写下的       | 按发布时间读取最新文章                           |
| 去我的媒体房间   | 根据已安装插件和已创建页面显示可用房间与真实数量 |

## 8. 配置相册、瞬间与友链

### 相册

在图库管理中为图片填写名称、描述与分组。Akari 使用分组作为筛选项，并按图片实际比例组织画廊；点击图片会打开带描述的灯箱。图片数量较多时，页面会用“继续展开”的方式追加内容。

### 瞬间

在瞬间插件中发布文字、图片或混合内容。Akari 会显示真实发布时间、标签和评论，并在列表底部继续追加下一批内容。

### 友链

在链接管理中维护分组和分组内顺序。建议每个链接填写：

- 站点名称；
- 完整 URL；
- Logo；
- 一句简洁描述；
- 所属分组。

友链页不显示评论。希望访客申请友链时，可以在“更多”菜单中同时放置友邻和留言簿入口。

## 9. 评论与留言簿

1. 安装并启用评论组件；
2. 在 Halo 评论设置中决定是否允许匿名评论、是否需要审核和验证码；
3. 在文章或留言簿页面设置中开启评论；
4. 使用访客窗口实际提交一条测试评论，确认审核策略符合预期。

Akari 使用 Halo 的评论数据与安全规则，但以主题自己的卡片、头像、回复框和加载方式呈现。评论关闭或插件不可用时，页面会显示明确的关闭状态，不会留下空白骨架。

## 10. 天气与访客隐私

开启“显示首页天气”后，浏览器会优先使用访客已经授予的定位权限；否则通过网络位置推断大致区域，再查询附近天气。天气结果只在访客浏览器中短时缓存，不会写入 Halo。

这项功能可能向 `ipwho.is`、Open-Meteo 或失败回退服务 `wttr.in` 发送访客 IP 或坐标。如果你的站点不需要天气，或隐私政策不允许这类外部请求，请关闭该选项。

站点启用了严格内容安全策略时，需要按实际使用情况允许：

```text
https://ipwho.is
https://api.open-meteo.com
https://wttr.in
```

## 11. 上线前检查清单

- [ ] 站点标题、副标题、头像、站长简介和 SEO 描述已经填写；
- [ ] 主题 Logo、首页主视觉、角色图和纸条文案符合站点气质；
- [ ] 所需插件已经安装、启用并录入真实内容；
- [ ] 六个自定义页面只创建了实际需要的部分，并选择了正确模板；
- [ ] 主菜单已经设置，桌面“更多”和移动端菜单顺序合理；
- [ ] 最近三篇文章都有合适的封面、摘要和分类；
- [ ] 媒体文章使用附件字段，播放器可以正常读取时长并播放；
- [ ] 留言簿和文章评论已用未登录访客身份测试；
- [ ] 明亮、深色、手机和宽屏至少各预览一次；
- [ ] 天气功能与站点隐私政策一致；
- [ ] 不存在指向未安装插件或未发布页面的菜单项。

完成以上步骤后，Akari 就会从“安装好的主题”变成真正属于你的晚灯小屋。
